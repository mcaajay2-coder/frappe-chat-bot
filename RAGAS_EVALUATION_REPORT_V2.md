## 🔬 2. Methodology & Scoring Rubrics

### 2.1 Live Execution Accuracy Protocol
Unlike traditional text-similarity or LLM-as-judge benchmarks, **KOINONIA RAGAS v2.1** executes both the **Generated Query ($Q_{\text{gen}}$)** and the **Verified Gold Standard Query ($Q_{\text{gold}}$)** against active MariaDB database instances:

$$\text{EA}(Q) = \begin{cases} 1.0 & \text{if } \text{Result}(Q_{\text{gen}}) = \text{Result}(Q_{\text{gold}}) \text{ (Exact set equality or matching scalar counts)} \\ 1.0 & \text{if } \text{RowCount}(Q_{\text{gen}}) = 0 \text{ and } \text{RowCount}(Q_{\text{gold}}) = 0 \text{ (Valid negative search)} \\ 0.0 & \text{if DB syntax error, over-selection (Gold=0, Gen>0), or zero records (Gold>0, Gen=0)} \end{cases}$$

> [!IMPORTANT]
> **Zero Fudging Standard:** No arbitrary partial credit ('Semantic Equivalent') is awarded when row counts diverge. If Gold is 0 and Generated is 8,000, or if Gold is 385 and Generated is 0, the test scores strictly **0.0 (Failed)**.

### 2.2 Confidence Interval Derivation
1. **Binomial Metrics (EA and VS):** Computed using the **95% Wilson Score Interval** with continuity adjustment:
$$w = \frac{p + \frac{z^2}{2n} \pm z \sqrt{\frac{p(1-p)}{n} + \frac{z^2}{4n^2}}}{1 + \frac{z^2}{n}} \quad (z = 1.96, n = 50)$$
2. **Continuous RAGAS Metrics (CP, CR, F, AR, CLSA):** Computed using **95% Empirical Bootstrap Confidence Intervals** (10,000 resamples) to properly reflect metric distributions without assuming artificial normality.
